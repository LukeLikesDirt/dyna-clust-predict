Does curated data fix EUKARYOME's cutoffs?

EUKARYOME's ITS2 similarity cutoffs run low on confidence for many fungal groups — the working theory is that metabarcoding-derived sequences are drowning out reliable ones. To test it, the CBS‑KNAW strain barcode set (ex‑type and manually validated cultures) was run through the identical cutoff-prediction pipeline, and compared against EUKARYOME’s existing ITS2 table wherever the same taxon was predicted in both.

What was compared

CBSITS is the CBS‑KNAW filamentous fungal strain barcode set (Vu, Groenewald, de Vries et al. 2019, Studies in Mycology) — ~12,000 ITS barcodes from ex‑type and manually validated cultures spanning ~7,300 accepted species. Every sequence traces back to a preserved, identified strain, which makes it a useful negative control against EUKARYOME’s much larger but more heterogeneous pool.

Its taxonomy headers were parsed into the same kingdom•phylum•class•order•family•genus•species schema EUKARYOME uses, restricted to the 11,674 records with a successful ITSx ITS2 extraction (of 11,715 total). The result is entirely Fungi — 81% Ascomycota, 14% Basidiomycota, the remainder early‑diverging lineages — dominated by common lab genera: Penicillium, Aspergillus, Fusarium, Colletotrichum, Chaetomium, Trichoderma.

The exact same R/predict.R sweep that produced EUKARYOME’s ITS2 table was then run on this set — identical thresholds, 0.001 step, and the same min_group_no = 10 / min_seq_no = 30 / max_proportion = 1.0 filters — across every rank→parent combination EUKARYOME's table covers.

Reading the result

The pattern holds up: swapping EUKARYOME’s mixed‑provenance sequences for CBSITS’s strain‑vouchered ones, within the same clade, lifts median confidence from 0.62 to 0.80 in 87% of matched taxa — while at species level the cut‑off value itself barely moves (median shift 0.004 across 119 matched genera/families). At this rank, curation is fixing how cleanly a threshold separates real groups, not where that threshold sits. That stability fades going up the hierarchy: the median cut‑off shift grows to 0.03 at genus and 0.08 at family, where curation starts relocating the threshold as well as sharpening it — consistent with metabarcoding noise piling up disproportionately in the larger, more heterogeneous higher‑rank subtrees.

That is direct support for the working theory: a curated, voucher‑only subset of EUKARYOME (filtered by specimen type or by excluding environmental/metabarcoding‑only accessions) is a promising next step, and this CBSITS comparison is a ready‑made benchmark for checking whether that filter actually moves confidence the way it should.

Three reasons not to oversell this

  • The four “global” rows compare different universes, not just different curation. EUKARYOME’s global rows are a random 20,000‑sequence sample across every kingdom in the database; CBSITS’s global rows are Fungi‑only. Their gap reflects scope as much as noise — treat them as context, not evidence.
  • Hypocreales is a real counter‑example, and it's informative. Genus‑within‑Hypocreales confidence drops from 0.44 to 0.13 under CBSITS — but CBSITS only captured 141 genera there against EUKARYOME’s 314, a much shallower, differently‑shaped sample of the same order. A handful of the 23 taxa (of 206) that got worse follow this same pattern: fewer, unevenly sampled groups, not curation backfiring.
  • CBSITS can only validate what it contains. It is entirely filamentous‑fungal, Ascomycota‑heavy, lab‑culturable taxa — no yeasts, no non‑fungal kingdoms, no obligate biotrophs or unculturable lineages. It's a clean test of the noise hypothesis inside its own footprint, not proof the fix generalises everywhere EUKARYOME's confidence is currently low.
